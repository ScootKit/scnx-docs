### Check if a user voted {#topgg-check-vote}

Asks top.gg whether a Discord user has a vote for your project that still counts. A vote counts for 12 hours.

**Inputs**

| Name | Type | Required | Details |
| --- | --- | --- | --- |
| Connection | [Text](../../../value-types.md#STRING) | No | The top.gg connection from the Integrations page that this action uses. Maximum length: 64 characters. |
| User ID | [Discord ID](../../../value-types.md#SNOWFLAKE) | Yes | The Discord ID of the user to check. |

**Outputs**

| Name | Type | Details |
| --- | --- | --- |
| Has voted | [Yes/No](../../../value-types.md#BOOLEAN) | Whether the user has a vote that still counts. |
| Voted at | [Date and time](../../../value-types.md#DATETIME) | When the user voted. Empty without a vote that counts. May be empty. |
| Expires at | [Date and time](../../../value-types.md#DATETIME) | When the vote stops counting. Empty without a vote that counts. May be empty. |
| Weight | [Whole number](../../../value-types.md#INTEGER) | How much the vote counts: 2 for weekend votes, otherwise 1. May be empty. |
