Read Steam profiles, what someone is playing and their games.

### Get Steam profile {#steam-get-player}

Reads a Steam profile, its online status and the game being played.

**Inputs**

| Name | Type | Required | Details |
| --- | --- | --- | --- |
| Connection | [Text](../../../value-types.md#STRING) | No | The Steam connection from the Integrations page that this action uses. Maximum length: 64 characters. |
| Steam ID | [ID](../../../value-types.md#ID) | Yes | The 17-digit Steam ID, for example 76561197960435530. Get it from a custom profile name with "Find Steam ID". Maximum length: 20 characters. |

**Outputs**

| Name | Type | Details |
| --- | --- | --- |
| Found | [Yes/No](../../../value-types.md#BOOLEAN) | Whether the profile exists. When not, everything else is empty. |
| Name | [Text](../../../value-types.md#STRING) | The profile name. May be empty. |
| Profile link | [URL](../../../value-types.md#URL) | The Steam profile page. May be empty. |
| Avatar | [URL](../../../value-types.md#URL) | The profile picture. May be empty. |
| Status | [Whole number](../../../value-types.md#INTEGER) | 0 offline (or private), 1 online, 2 busy, 3 away, 4 snooze, 5 looking to trade, 6 looking to play. May be empty. |
| Public profile | [Yes/No](../../../value-types.md#BOOLEAN) | Whether the profile is public. May be empty. |
| Playing | [Text](../../../value-types.md#STRING) | The game being played right now. Empty when none or private. May be empty. |
| Playing app ID | [ID](../../../value-types.md#ID) | The app ID of the game being played. May be empty. |
| Country | [Text](../../../value-types.md#STRING) | The two-letter country code, when shown. May be empty. |
| Created at | [Date and time](../../../value-types.md#DATETIME) | When the account was created, when shown. May be empty. |
| Last online | [Date and time](../../../value-types.md#DATETIME) | When the user was last online, when shown. May be empty. |

### Find Steam ID {#steam-find-steam-id}

Turns a custom profile name (the part after steamcommunity.com/id/) into the Steam ID.

**Inputs**

| Name | Type | Required | Details |
| --- | --- | --- | --- |
| Connection | [Text](../../../value-types.md#STRING) | No | The Steam connection from the Integrations page that this action uses. Maximum length: 64 characters. |
| Custom profile name | [Text](../../../value-types.md#STRING) | Yes | The custom name in the profile address, for example gabelogannewell. Maximum length: 32 characters. |

**Outputs**

| Name | Type | Details |
| --- | --- | --- |
| Found | [Yes/No](../../../value-types.md#BOOLEAN) | Whether a profile has this name. When not, the Steam ID is empty. |
| Steam ID | [ID](../../../value-types.md#ID) | The 17-digit Steam ID. May be empty. |

### Get owned games {#steam-get-owned-games}

Lists the games of a Steam user, most played first. Only works for public game details.

**Inputs**

| Name | Type | Required | Details |
| --- | --- | --- | --- |
| Connection | [Text](../../../value-types.md#STRING) | No | The Steam connection from the Integrations page that this action uses. Maximum length: 64 characters. |
| Steam ID | [ID](../../../value-types.md#ID) | Yes | The 17-digit Steam ID, for example 76561197960435530. Get it from a custom profile name with "Find Steam ID". Maximum length: 20 characters. |

**Outputs**

| Name | Type | Details |
| --- | --- | --- |
| Visible | [Yes/No](../../../value-types.md#BOOLEAN) | Whether the game list could be read. False for private profiles; then the rest is empty. |
| Games | [Whole number](../../../value-types.md#INTEGER) | How many games the user owns. May be empty. |
| Game list | List of [Steam game](../../../value-types.md#steam-Game) | The games, most played first. May be empty. |
