Read rows from the tables of your Airtable bases.

### Get rows {#airtable.list-rows}

Reads one page of rows of a table, optionally of a view or matching a formula.

**Inputs**

| Name | Type | Required | Details |
| --- | --- | --- | --- |
| Connection | [Text](../../../value-types.md#STRING) | No | The Airtable connection from the Integrations page that this action uses. Maximum length: 64 characters. |
| Base ID | [Text](../../../value-types.md#STRING) | Yes | The ID of the base, starting with app. It is in the base's address. Maximum length: 30 characters. |
| Table | [Text](../../../value-types.md#STRING) | Yes | The name or ID (starting with tbl) of the table. Maximum length: 100 characters. |
| View | [Text](../../../value-types.md#STRING) | No | The name or ID of a view. Its filters and order apply. Maximum length: 100 characters. |
| Formula | [Text](../../../value-types.md#STRING) | No | An Airtable formula rows must match, for example "\{Status\} = 'Open'". Maximum length: 2000 characters. |
| How many | [Whole number](../../../value-types.md#INTEGER) | No | How many rows per page, 1 to 100. Empty: 20. Value: 1 to 100. Default: `20`. |
| Next page | [Text](../../../value-types.md#STRING) | No | The "Next page" output of the previous call. Empty: the first page. Maximum length: 200 characters. |

**Outputs**

| Name | Type | Details |
| --- | --- | --- |
| Rows | List of [Airtable row](../../../value-types.md#airtable:Row) | The rows of this page. |
| Next page | [Text](../../../value-types.md#STRING) | Pass this to the next call to get the next page. Empty on the last page. May be empty. |

### Get row {#airtable.get-row}

Reads one row by its ID.

**Inputs**

| Name | Type | Required | Details |
| --- | --- | --- | --- |
| Connection | [Text](../../../value-types.md#STRING) | No | The Airtable connection from the Integrations page that this action uses. Maximum length: 64 characters. |
| Base ID | [Text](../../../value-types.md#STRING) | Yes | The ID of the base, starting with app. It is in the base's address. Maximum length: 30 characters. |
| Table | [Text](../../../value-types.md#STRING) | Yes | The name or ID (starting with tbl) of the table. Maximum length: 100 characters. |
| Row ID | [Text](../../../value-types.md#STRING) | Yes | The ID of the row, starting with rec. Maximum length: 30 characters. |

**Outputs**

| Name | Type | Details |
| --- | --- | --- |
| Found | [Yes/No](../../../value-types.md#BOOLEAN) | Whether the row exists. When not, the row is empty. |
| Row | [Airtable row](../../../value-types.md#airtable:Row) | The row. May be empty. |
