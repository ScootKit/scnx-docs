Read GitHub repositories, issues, releases and users, and open issues.

### Get repository {#github-get-repo}

Reads a repository: description, stars, forks and open issues.

**Inputs**

| Name       | Type                                   | Required | Details                                                                                                |
| ---------- | -------------------------------------- | -------- | ------------------------------------------------------------------------------------------------------ |
| Connection | [Text](../../../value-types.md#STRING) | No       | The GitHub connection from the Integrations page that this action uses. Maximum length: 64 characters. |
| Owner      | [Text](../../../value-types.md#STRING) | Yes      | The user or organization that owns the repository, for example octocat. Maximum length: 39 characters. |
| Repository | [Text](../../../value-types.md#STRING) | Yes      | The name of the repository, for example hello-world. Maximum length: 100 characters.                   |

**Outputs**

| Name           | Type                                              | Details                                                                                     |
| -------------- | ------------------------------------------------- | ------------------------------------------------------------------------------------------- |
| Found          | [Yes/No](../../../value-types.md#BOOLEAN)         | Whether the repository exists and the token can see it. When not, everything else is empty. |
| Full name      | [Text](../../../value-types.md#STRING)            | owner/name of the repository. May be empty.                                                 |
| Description    | [Text](../../../value-types.md#STRING)            | The description. May be empty.                                                              |
| Link           | [URL](../../../value-types.md#URL)                | The repository on GitHub. May be empty.                                                     |
| Stars          | [Whole number](../../../value-types.md#INTEGER)   | How many stars it has. May be empty.                                                        |
| Forks          | [Whole number](../../../value-types.md#INTEGER)   | How many forks it has. May be empty.                                                        |
| Open issues    | [Whole number](../../../value-types.md#INTEGER)   | Open issues and pull requests together. May be empty.                                       |
| Language       | [Text](../../../value-types.md#STRING)            | The main programming language. May be empty.                                                |
| Default branch | [Text](../../../value-types.md#STRING)            | The default branch, for example main. May be empty.                                         |
| Archived       | [Yes/No](../../../value-types.md#BOOLEAN)         | Whether the repository is archived. May be empty.                                           |
| Last push      | [Date and time](../../../value-types.md#DATETIME) | When code was last pushed. May be empty.                                                    |
