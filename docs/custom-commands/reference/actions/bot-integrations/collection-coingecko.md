Read cryptocurrency prices, coin details and market rankings from CoinGecko.

### Get coin price {#coingecko-get-price}

Reads the current price of one coin in one currency.

**Inputs**

| Name       | Type                                   | Required | Details                                                                                                                                                  |
| ---------- | -------------------------------------- | -------- | -------------------------------------------------------------------------------------------------------------------------------------------------------- |
| Connection | [Text](../../../value-types.md#STRING) | No       | The CoinGecko connection from the Integrations page that this action uses. Maximum length: 64 characters.                                                |
| Coin ID    | [Text](../../../value-types.md#STRING) | Yes      | The CoinGecko API ID of the coin, for example bitcoin or ethereum. It is shown as "API ID" on the coin's CoinGecko page. Maximum length: 100 characters. |
| Currency   | [Text](../../../value-types.md#STRING) | No       | The currency for prices, for example usd, eur or btc. Empty: usd. Maximum length: 10 characters. Default: `usd`.                                         |

**Outputs**

| Name                    | Type                                              | Details                                                                                |
| ----------------------- | ------------------------------------------------- | -------------------------------------------------------------------------------------- |
| Found                   | [Yes/No](../../../value-types.md#BOOLEAN)         | Whether CoinGecko knows the coin and the currency. When not, everything else is empty. |
| Price                   | [Decimal number](../../../value-types.md#FLOAT)   | The price in the chosen currency. May be empty.                                        |
| Market cap              | [Decimal number](../../../value-types.md#FLOAT)   | The market cap in the chosen currency. May be empty.                                   |
| Change in 24 hours in % | [Decimal number](../../../value-types.md#FLOAT)   | How much the price changed in the last 24 hours, in percent. May be empty.             |
| Updated at              | [Date and time](../../../value-types.md#DATETIME) | When CoinGecko last updated the price. May be empty.                                   |

### Get top coins {#coingecko-list-markets}

Lists the coins with the highest market cap, the largest first.

**Inputs**

| Name       | Type                                            | Required | Details                                                                                                          |
| ---------- | ----------------------------------------------- | -------- | ---------------------------------------------------------------------------------------------------------------- |
| Connection | [Text](../../../value-types.md#STRING)          | No       | The CoinGecko connection from the Integrations page that this action uses. Maximum length: 64 characters.        |
| Currency   | [Text](../../../value-types.md#STRING)          | No       | The currency for prices, for example usd, eur or btc. Empty: usd. Maximum length: 10 characters. Default: `usd`. |
| How many   | [Whole number](../../../value-types.md#INTEGER) | No       | How many coins to get, 1 to 100. Empty: 10. Value: 1 to 100. Default: `10`.                                      |
| Page       | [Whole number](../../../value-types.md#INTEGER) | No       | Which page of the list, starting at 1. Empty: 1. Value: 1 to 1000. Default: `1`.                                 |

**Outputs**

| Name  | Type                                                             | Details                       |
| ----- | ---------------------------------------------------------------- | ----------------------------- |
| Coins | List of [CoinGecko coin](../../../value-types.md#coingecko-Coin) | The coins, the largest first. |
