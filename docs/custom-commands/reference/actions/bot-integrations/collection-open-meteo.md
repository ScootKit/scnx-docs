Find places and read the current weather and the daily forecast. No account needed.

### Find a place {#open-meteo-find-place}

Looks up a city or place by name and gives its coordinates for the weather actions. Uses the best match.

**Inputs**

| Name       | Type                                   | Required | Details                                                                                                               |
| ---------- | -------------------------------------- | -------- | --------------------------------------------------------------------------------------------------------------------- |
| Place name | [Text](../../../value-types.md#STRING) | Yes      | The name of the city or place, for example Berlin. Maximum length: 100 characters.                                    |
| Language   | [Text](../../../value-types.md#STRING) | No       | Two-letter language code for the place names, for example de. Empty: en. Maximum length: 2 characters. Default: `en`. |

**Outputs**

| Name         | Type                                            | Details                                                        |
| ------------ | ----------------------------------------------- | -------------------------------------------------------------- |
| Found        | [Yes/No](../../../value-types.md#BOOLEAN)       | Whether a place was found. When not, everything else is empty. |
| Name         | [Text](../../../value-types.md#STRING)          | The name of the place. May be empty.                           |
| Latitude     | [Decimal number](../../../value-types.md#FLOAT) | The latitude of the place. May be empty.                       |
| Longitude    | [Decimal number](../../../value-types.md#FLOAT) | The longitude of the place. May be empty.                      |
| Country      | [Text](../../../value-types.md#STRING)          | The country the place is in. May be empty.                     |
| Country code | [Text](../../../value-types.md#STRING)          | The two-letter country code, for example DE. May be empty.     |
| Region       | [Text](../../../value-types.md#STRING)          | The state or region, for example Bavaria. May be empty.        |
| Time zone    | [Text](../../../value-types.md#STRING)          | The time zone, for example Europe/Berlin. May be empty.        |
| Population   | [Whole number](../../../value-types.md#INTEGER) | How many people live there, when known. May be empty.          |

### Get current weather {#open-meteo-get-current-weather}

Reads the weather right now at a place.

**Inputs**

| Name             | Type                                            | Required | Details                                                                                        |
| ---------------- | ----------------------------------------------- | -------- | ---------------------------------------------------------------------------------------------- |
| Latitude         | [Decimal number](../../../value-types.md#FLOAT) | Yes      | The latitude of the place, for example 52.52. Get it with "Find a place". Value: -90 to 90.    |
| Longitude        | [Decimal number](../../../value-types.md#FLOAT) | Yes      | The longitude of the place, for example 13.41. Get it with "Find a place". Value: -180 to 180. |
| Temperature unit | [Text](../../../value-types.md#STRING)          | No       | celsius or fahrenheit. Empty: celsius. Maximum length: 10 characters. Default: `celsius`.      |
| Wind speed unit  | [Text](../../../value-types.md#STRING)          | No       | kmh, ms, mph or kn. Empty: kmh. Maximum length: 3 characters. Default: `kmh`.                  |

**Outputs**

| Name                | Type                                              | Details                                                                                                                                                                                                       |
| ------------------- | ------------------------------------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| Temperature         | [Decimal number](../../../value-types.md#FLOAT)   | The air temperature, in the chosen unit.                                                                                                                                                                      |
| Feels like          | [Decimal number](../../../value-types.md#FLOAT)   | How warm it feels, in the chosen unit. May be empty.                                                                                                                                                          |
| Temperature unit    | [Text](../../../value-types.md#STRING)            | The unit sign, for example °C. May be empty.                                                                                                                                                                  |

| Weather code        | [Whole number](../../../value-types.md#INTEGER)   | The WMO weather code: 0 clear, 1 to 3 partly cloudy to overcast, 45 and 48 fog, 51 to 67 drizzle and rain, 71 to 77 snow, 80 to 82 rain showers, 85 and 86 snow showers, 95 to 99 thunderstorm. May be empty. |
| Wind speed          | [Decimal number](../../../value-types.md#FLOAT)   | The wind speed, in the chosen unit. May be empty.                                                                                                                                                             |
| Is daytime          | [Yes/No](../../../value-types.md#BOOLEAN)         | Whether the sun is up at the place.                                                                                                                                                                           |

### Get weather forecast {#open-meteo-get-forecast}

Reads the daily forecast for a place, today first.

**Inputs**

| Name             | Type                                            | Required | Details                                                                                        |
| ---------------- | ----------------------------------------------- | -------- | ---------------------------------------------------------------------------------------------- |
| Latitude         | [Decimal number](../../../value-types.md#FLOAT) | Yes      | The latitude of the place, for example 52.52. Get it with "Find a place". Value: -90 to 90.    |
| Longitude        | [Decimal number](../../../value-types.md#FLOAT) | Yes      | The longitude of the place, for example 13.41. Get it with "Find a place". Value: -180 to 180. |
| Days             | [Whole number](../../../value-types.md#INTEGER) | No       | How many days to get, 1 to 16. Empty: 7. Value: 1 to 16. Default: `7`.                         |
| Temperature unit | [Text](../../../value-types.md#STRING)          | No       | celsius or fahrenheit. Empty: celsius. Maximum length: 10 characters. Default: `celsius`.      |
| Wind speed unit  | [Text](../../../value-types.md#STRING)          | No       | kmh, ms, mph or kn. Empty: kmh. Maximum length: 3 characters. Default: `kmh`.                  |

**Outputs**

| Name             | Type                                                           | Details                                                              |
| ---------------- | -------------------------------------------------------------- | -------------------------------------------------------------------- |
| Days             | List of [Forecast day](../../../value-types.md#open-meteo-Day) | The forecast, one entry per day, today first.                        |
| Time zone        | [Text](../../../value-types.md#STRING)                         | The time zone of the place, for example Europe/Berlin. May be empty. |
| Temperature unit | [Text](../../../value-types.md#STRING)                         | The unit sign, for example °C. May be empty.                         |
