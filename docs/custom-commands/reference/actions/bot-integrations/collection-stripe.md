### Create Checkout session {#stripe.create-checkout-session}

Creates a Stripe page where one customer pays for one item. Sending the same inputs again returns the same session.

**Inputs**

| Name | Type | Required | Details |
| --- | --- | --- | --- |
| Connection | [Text](../../../value-types.md#STRING) | No | The Stripe connection from the Integrations page that this action uses. Maximum length: 64 characters. |

| Price | [Whole number](../../../value-types.md#INTEGER) | Yes | The amount in the smallest unit of the currency, for example cents: 1000 is 10.00. Value: 0 to 99999999. |
| Quantity | [Whole number](../../../value-types.md#INTEGER) | No | How many of it, 1 to 999. Empty: 1. Value: 1 to 999. Default: `1`. |
| Currency | [Text](../../../value-types.md#STRING) | Yes | The three-letter currency code, for example eur. Length: 3 to 3 characters. |
| Success link | [Text](../../../value-types.md#STRING) | Yes | Where the customer lands after paying. Maximum length: 2048 characters. |
| Cancel link | [Text](../../../value-types.md#STRING) | No | Where the customer lands when they go back. Empty: no back button. Maximum length: 2048 characters. |
| Reference | [Text](../../../value-types.md#STRING) | Yes | Your own ID for this order, for example an order number. Use it to find the order again. Maximum length: 200 characters. |
| Customer email | [Text](../../../value-types.md#STRING) | No | Fills in the email on the Stripe page. Empty: the customer types it. Maximum length: 800 characters. |
| Metadata | Lookup table of [Text](../../../value-types.md#STRING) to [Text](../../../value-types.md#STRING) | No | Notes Stripe stores with it, as name and value pairs, for example an order number. Empty: none. |
| Expires at | [Date and time](../../../value-types.md#DATETIME) | No | When the page stops working. Stripe needs a time between 30 minutes and 24 hours from now. Work it out once and keep it with the order. Empty: 24 hours. |

**Outputs**

| Name | Type | Details |
| --- | --- | --- |
| ID | [ID](../../../value-types.md#ID) | The ID, starting with cs_. |
| Payment page | [URL](../../../value-types.md#URL) | The Stripe page where the customer pays. Empty once the session expired. May be empty. |
| Status | [Text](../../../value-types.md#STRING) | open, complete or expired. |
| Payment status | [Text](../../../value-types.md#STRING) | paid, unpaid or no_payment_required. |
| Expires at | [Date and time](../../../value-types.md#DATETIME) | When the session expires. |
| Total | [Whole number](../../../value-types.md#INTEGER) | The amount in the smallest unit of the currency, for example cents: 1000 is 10.00. May be empty. |
| Currency | [Text](../../../value-types.md#STRING) | The currency, for example eur. May be empty. |
| Reference | [Text](../../../value-types.md#STRING) | The reference you gave when creating the session. May be empty. |
| Payment ID | [ID](../../../value-types.md#ID) | The payment (pi_...), once the customer started paying. May be empty. |

### Create refund {#stripe.create-refund}

Refunds a payment, in full or in part. Give the payment ID or the charge ID. Sending the same refund again right away returns the first refund and refunds nothing more. To refund the same amount twice on purpose, change an input.

**Inputs**

| Name | Type | Required | Details |
| --- | --- | --- | --- |
| Connection | [Text](../../../value-types.md#STRING) | No | The Stripe connection from the Integrations page that this action uses. Maximum length: 64 characters. |
| Payment ID | [ID](../../../value-types.md#ID) | No | The payment to refund (pi_...). Give this or the charge ID. Maximum length: 255 characters. |
| Charge ID | [ID](../../../value-types.md#ID) | No | The charge to refund (ch_...). Give this or the payment ID. Maximum length: 255 characters. |
| Amount | [Whole number](../../../value-types.md#INTEGER) | No | How much to refund, in the smallest unit of the currency, for example cents. Empty: everything that is left. Value: 1 to 99999999. |
| Reason | [Text](../../../value-types.md#STRING) | No | duplicate, fraudulent or requested_by_customer. Empty: none. Allowed values: `duplicate`, `fraudulent`, `requested_by_customer`. |
| Metadata | Lookup table of [Text](../../../value-types.md#STRING) to [Text](../../../value-types.md#STRING) | No | Notes Stripe stores with it, as name and value pairs, for example an order number. Empty: none. |

**Outputs**

| Name | Type | Details |
| --- | --- | --- |
| ID | [ID](../../../value-types.md#ID) | The ID, starting with re_. |
| Status | [Text](../../../value-types.md#STRING) | succeeded, pending, requires_action, failed or canceled. |
| Amount | [Whole number](../../../value-types.md#INTEGER) | The amount in the smallest unit of the currency, for example cents: 1000 is 10.00. |
| Currency | [Text](../../../value-types.md#STRING) | The currency, for example eur. |
