Create lookup tables and read, set and remove values by key.

### Create lookup table {#create-map}

Creates a new, empty lookup table. Add entries with "Lookup table: set value", which hands back a new lookup table every time. To fill a lookup table across several steps, or inside a loop, use "Create lookup table builder" instead.

**Outputs**

| Name | Type | Details |
| --- | --- | --- |
| Lookup table | Lookup table of [Text](../../../value-types.md#STRING) to [Text](../../../value-types.md#STRING) | The new empty lookup table. |

### Lookup table: get value {#map-get}

Returns the value stored under a key in the lookup table.

**Inputs**

| Name | Type | Required | Details |
| --- | --- | --- | --- |
| Lookup table | Lookup table of [Text](../../../value-types.md#STRING) to [Any](../../../value-types.md#ANY) | Yes | Lookup table to read from. |
| Key | [Text](../../../value-types.md#STRING) | Yes | Key to look up. |

**Outputs**

| Name | Type | Details |
| --- | --- | --- |
| Value | [Item](../../../value-types.md#ELEMENT) | Value stored under the key, or empty when the key is missing. May be empty. |

### Lookup table: set value {#map-set}

Hands back a new lookup table with the key set to the value and leaves the lookup table you gave it unchanged, so use the result in the next step. To fill a lookup table across several steps, or inside a loop, use "Create lookup table builder" and "Lookup table builder: set value" instead.

**Inputs**

| Name | Type | Required | Details |
| --- | --- | --- | --- |
| Lookup table | Lookup table of [Text](../../../value-types.md#STRING) to [Text](../../../value-types.md#STRING) | Yes | The original lookup table. It is not changed. |
| Key | [Text](../../../value-types.md#STRING) | Yes | Key to set. |
| Value | [Text](../../../value-types.md#STRING) | Yes | Value to store under the key. |

**Outputs**

| Name | Type | Details |
| --- | --- | --- |
| Result | Lookup table of [Text](../../../value-types.md#STRING) to [Text](../../../value-types.md#STRING) | The new lookup table, with the key set. |

### Lookup table from entries {#map-from-entries}

Builds a lookup table from key and value entries or storage leaderboard entries. Storage subjects become keys. When a key appears more than once, the later entry wins.
