Builders collect text, lists, lookup tables or numbers across many steps, including inside a loop, and give you the result once at the end. Adding to a builder changes the builder itself.

### Create text builder {#create-text-buffer}

Creates a text builder: text that later steps append to in place, so anything appended inside a loop is still there afterwards, and that you read out once at the end. Efficient for building large text (e.g. transcripts or reports) without re-joining on every step. The builder only lasts for this execution and is lost after a wait/resume.

**Inputs**

| Name | Type | Required | Details |
| --- | --- | --- | --- |
| Initial text | [Text](../../../value-types.md#STRING) | No | Optional text to start the builder with (empty if not set). |

**Outputs**

| Name | Type | Details |
| --- | --- | --- |
| Text builder | [Text builder](../../../value-types.md#TEXT_BUFFER) | The new text builder. Use it in the other "Text builder" steps. |

### Text builder: append text {#append-to-buffer}

Appends text to a text builder. This changes the builder itself, so there is nothing to pass on, and text appended inside a loop is still there after the loop ends. If a separator is set, it is inserted before the text only when the builder is not already empty (so a list builds "a, b, c" with no leading separator).

**Inputs**

| Name | Type | Required | Details |
| --- | --- | --- | --- |
| Text builder | [Text builder](../../../value-types.md#TEXT_BUFFER) | Yes | The text builder to append to. |
| Text | [Text](../../../value-types.md#STRING) | Yes | The text to append. |
| Separator | [Text](../../../value-types.md#STRING) | No | Optional separator inserted before the text when the builder is not empty (e.g. ", " or a newline). |

### Text builder: read the text {#buffer-to-string}

Reads a text builder out as an ordinary text you can pass to the other text steps. The builder is not emptied and can still be appended to afterwards, and the text you get is a snapshot, so later appends do not reach it.

### Create lookup table builder {#create-map-builder}

Creates a lookup table builder: a lookup table that later steps change in place, so entries you set inside a loop are still there afterwards, and that you read out once at the end. This is the difference from "Lookup table: set value", which leaves the lookup table you gave it alone and hands back a new one. The builder only lasts for this execution and is lost after a wait/resume.
