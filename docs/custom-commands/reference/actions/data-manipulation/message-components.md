**Inputs**

| Name | Type | Required | Details |

| Show Percentage | [Yes/No](../../../value-types.md#BOOLEAN) | No | Append the rounded percentage after the bar. Default: No. |

**Outputs**

| Name | Type | Details |

| Text | [Text](../../../value-types.md#STRING) | The rendered progress bar. |
