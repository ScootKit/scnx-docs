### Build autocomplete choices {#build-autocomplete-choices}

Turns a list of runtime values (e.g. stored keys) into autocomplete choices to feed into "Send autocomplete response". Optionally filters them by what the user has typed.

**Inputs**

| Name | Type | Required | Details |
| --- | --- | --- | --- |
| Items | List of [Any](../../../value-types.md#ANY) | Yes | The values to offer. Texts are used as-is; lookup table entries use their key; storage entries use their subject. |
| Label path | [Text](../../../value-types.md#STRING) | No | Which field of each item to show, e.g. "name". Leave blank to use the item itself. Maximum length: 100 characters. |
| Value path | [Text](../../../value-types.md#STRING) | No | Which field of each item to send back, e.g. "id". Defaults to the label. Maximum length: 100 characters. |
| Filter | [Text](../../../value-types.md#STRING) | No | Optional. Keep only items matching this text (case-insensitive, prefix matches first). Use the option's typed value here for live filtering. |
| Limit | [Whole number](../../../value-types.md#INTEGER) | No | Optional. Maximum number of choices to return (1 - 25, default 25). Value: 1 to 25. Default: `25`. |

**Outputs**

| Name | Type | Details |
| --- | --- | --- |
| Choices | List of [Command option choice](../../../value-types.md#APPLICATION_COMMAND_OPTION_CHOICE) | The built autocomplete choices, ready for "Send autocomplete response". |

### Convert to ID {#to-id}

Turns text or a whole number into an ID. An ID keeps its exact characters however long it is, so it is safe for Discord IDs and for ids from other services. Fails on empty text.

**Inputs**

| Name | Type | Required | Details |
| --- | --- | --- | --- |
| Text | [Text](../../../value-types.md#STRING) | No | The text to use as the ID. Use this or Number. Use only one of these: Number. |
| Number | [Whole number](../../../value-types.md#INTEGER) | No | A whole number to use as the ID. Use this or Text. Use only one of these: Text. |

**Outputs**

| Name | Type | Details |
| --- | --- | --- |
| ID | [ID](../../../value-types.md#ID) | The ID. |

### Build message link {#build-message-link}

Builds a Discord message link (jump URL), either from a Message value or from a server, channel, and message ID. The Message value takes priority when both are provided; the server segment is @me for a direct message.

**Inputs**

| Name | Type | Required | Details |
| --- | --- | --- | --- |
| Message | [Message](../../../value-types.md#MESSAGE) | No | The message to build a link for. Takes priority over the IDs below. Use only one of these: Channel ID. |
| Server ID | [Discord ID](../../../value-types.md#SNOWFLAKE) | No | The server ID, or empty for a direct-message link. Used when Message is not set. |
| Channel ID | [Discord ID](../../../value-types.md#SNOWFLAKE) | No | The channel ID. Used when Message is not set. Use only one of these: Message. |
| Message ID | [Discord ID](../../../value-types.md#SNOWFLAKE) | No | The message ID. Used when Message is not set. |

**Outputs**

| Name | Type | Details |
| --- | --- | --- |
| Message link | [URL](../../../value-types.md#URL) | The built Discord message link (jump URL). |
