Actions in the category "Message polls".

### Create poll {#create-poll}

Creates a new poll message in a channel using simple answer inputs.

Required permissions: Create polls.

**Inputs**

| Name | Type | Required | Details |
| --- | --- | --- | --- |
| Channel | [Server channel](../../../value-types.md#GUILD_CHANNEL) | Yes | The channel where the poll will be posted. |
| Question | [Text](../../../value-types.md#STRING) | Yes | The poll question (max 300 characters). Length: 1 to 300 characters. |
| Answers | List of [Poll answer](../../../value-types.md#POLL_ANSWER_INPUT) | Yes | List of poll answers (1-10). Items: 1 to 10. |
| Duration (hours) | [Whole number](../../../value-types.md#INTEGER) | No | How long the poll stays open in hours (1-768). Value: 1 to 768. Default: `24`. |
| Allow Multiple Answers | [Yes/No](../../../value-types.md#BOOLEAN) | No | Whether voters may select more than one answer. Default: No. |

**Outputs**

| Name | Type | Details |
| --- | --- | --- |
| Poll Message | [Message](../../../value-types.md#MESSAGE) | The poll message that was sent. |
