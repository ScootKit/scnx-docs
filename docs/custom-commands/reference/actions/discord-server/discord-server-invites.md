Actions in the category "Server invites".

### Create invite {#create-invite}

Creates an invite for a channel.

Required permissions: Manage server.

**Inputs**

| Name | Type | Required | Details |
| --- | --- | --- | --- |
| Channel | [Server channel](../../../value-types.md#GUILD_CHANNEL) | Yes | Channel the invite leads to. |
| Max age | [Duration](../../../value-types.md#DURATION) | Yes | How long the invite remains valid (0 = never expires). Value: 0 to 604800000. Default: `86400000`. |
| Max uses | [Whole number](../../../value-types.md#INTEGER) | Yes | How many times the invite may be used (0 = unlimited). Value: 0 to 100. Default: `0`. |
| Temporary | [Yes/No](../../../value-types.md#BOOLEAN) | Yes | Kick members on disconnect if they have no role. Default: No. |
| Unique | [Yes/No](../../../value-types.md#BOOLEAN) | Yes | Always create a fresh code, never reuse an existing one. Default: No. |

**Outputs**

| Name | Type | Details |
| --- | --- | --- |
| Invite | [Invite](../../../value-types.md#GUILD_INVITE) | The created invite. |
