### Create role {#create-role}

Creates a new role on your server.

Required permissions: Manage roles.

**Inputs**

| Name | Type | Required | Details |

| Permissions | List of [Permission](../../../value-types.md#PERMISSION_FLAG) | Yes | Permissions granted by the role. Default: `[]`. |
| Audit log reason | [Text](../../../value-types.md#STRING) | No | Reason recorded in the audit log. Maximum length: 512 characters. |
