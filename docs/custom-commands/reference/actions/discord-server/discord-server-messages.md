### Send paginated message {#send-paginated-message}

Sends a message with prev/next buttons that page through a list of message contents. The page state is stored durably, so paging keeps working after a bot restart.

Required permissions: View channel, Send messages.

**Inputs**

| Name | Type | Required | Details |
| --- | --- | --- | --- |
| Channel | [Text channel](../../../value-types.md#GUILD_TEXT_CHANNEL) | Yes | Channel to send the paginated message to. |
| Pages | List of [Message content](../../../value-types.md#MESSAGE_CONTENT) | Yes | The list of pages (message contents) to page through, e.g. built with Create message pages and Add message page. Max 100. Maximum items: 100. |
| Restrict to user | [User](../../../value-types.md#DISCORD_USER) | No | By default, only the user who triggered the flow can page through the message. Set a user here to lock paging to someone else instead. On flows with no triggering user (e.g. scheduled or automatic flows), anyone can page. |
| Timeout | [Duration](../../../value-types.md#DURATION) | No | How long the buttons stay active before the paginated message expires. Defaults to 24 hours; capped at 7 days. Value: 60000 to 604800000. |

**Outputs**

| Name | Type | Details |
| --- | --- | --- |
| Sent message | [Message](../../../value-types.md#MESSAGE) | The paginated message that was sent. |
