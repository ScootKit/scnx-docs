### Member has permission {#member-has-permission}

Checks whether a member has a given permission. Without a channel this checks their server-wide permissions; with a channel it checks their effective permissions there, including channel overwrites. Administrators and the server owner count as having every permission.

**Inputs**

| Name | Type | Required | Details |
| --- | --- | --- | --- |
| Member | [Server member](../../../value-types.md#GUILD_MEMBER) | Yes | Member to check. |
| Permission | [Permission](../../../value-types.md#PERMISSION_FLAG) | Yes | Permission to check for. |
| Channel | [Server channel](../../../value-types.md#GUILD_CHANNEL) | No | Optional. Check the permission inside this channel (overwrites applied) instead of server-wide. |

**Outputs**

| Name | Type | Details |
| --- | --- | --- |
| Has permission | [Yes/No](../../../value-types.md#BOOLEAN) | True if the member has the permission. |
