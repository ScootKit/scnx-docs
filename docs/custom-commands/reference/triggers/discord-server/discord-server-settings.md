Triggers in the category "Server settings".

### Server onboarding updated {#guild-onboarding-updated}

Triggers when the onboarding configuration of a server is changed (derived from the audit log - the bot needs the View Audit Log permission). The previous configuration is not available and is always empty.

Required intents: `GuildModeration`.

**Outputs**

| Name | Type | Details |
| --- | --- | --- |
| Server | [Server](../../../value-types.md#GUILD) | The server whose onboarding changed. |
| Previous Onboarding | [Server onboarding](../../../value-types.md#GUILD_ONBOARDING) | Onboarding state before the update. May be empty. |
| Current Onboarding | [Server onboarding](../../../value-types.md#GUILD_ONBOARDING) | Onboarding state after the update. May be empty. |

### Welcome screen updated {#welcome-screen-updated}

Triggers when the welcome screen is changed BY A FLOW (the "Update welcome screen" action). Changes made directly in the Discord client do not fire this trigger.

**Outputs**

| Name | Type | Details |
| --- | --- | --- |
| Server | [Server](../../../value-types.md#GUILD) | The server whose welcome screen changed. |
| Previous Screen | [Welcome screen](../../../value-types.md#WELCOME_SCREEN) | Welcome screen before the update. |
| Current Screen | [Welcome screen](../../../value-types.md#WELCOME_SCREEN) | Welcome screen after the update. |
