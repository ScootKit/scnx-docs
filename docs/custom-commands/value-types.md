Every input, output and provided value of a trigger or action has a type. The type decides which values you can connect to it and which values it accepts. Each type name in the reference tables links to its entry on this page.

| Name | Details |
| --- | --- |
| [Basic types](#basic-types) | Plain values such as text, numbers, yes/no values and times. |
| [Lists and lookup tables](#lists-and-lookup-tables) | Lists and lookup tables hold several values. In the reference tables they are shown together with the type of their items, for example "List of Text". |
| [Choice lists](#choice-lists) | Values that are picked from a fixed list of choices. |
| [Objects](#objects) | Things such as channels, members or messages. Each has fields you can read in your flow. |
| [Special types](#special-types) | Types whose exact shape depends on how and where they are used. |

## Basic types {#basic-types}

Plain values such as text, numbers, yes/no values and times.

### Text {#STRING}

Example: `Hello there`.

### Whole number {#INTEGER}

### Decimal number {#FLOAT}

### Large whole number {#BIGINT}

Example: `9007199254740993`.

### Yes/No {#BOOLEAN}

Example: `Yes`.

### Discord ID {#SNOWFLAKE}

Example: `123456789012345678`.

### ID {#ID}

Example: `A1B2-C3D4`.

### Date and time {#DATETIME}

Example: `Oct 1, 2026, 6:30 PM`.

### Duration {#DURATION}

Example: `5 minutes`.

### URL {#URL}

Example: `https://example.com`.

### Color {#COLOR}

## Special types {#special-types}

Types whose exact shape depends on how and where they are used.

### Either user or role {#MENTIONABLE}

Either a user (or member) or a role, as a user-or-role option or picker returns it. Use "Switch on kind" to work with one kind.

Example: `@Alex or @Moderators`. Either one of: [User](#DISCORD_USER), [Role](#GUILD_ROLE).

### Audit log details {#AUDIT_LOG_DETAILS}

Extra data of an audit log entry. Which fields it has depends on the entry's action.

Either one of: [Prune details](#AUDIT_LOG_DETAILS_PRUNE), [Channel and count details](#AUDIT_LOG_DETAILS_CHANNEL_COUNT), [Count details](#AUDIT_LOG_DETAILS_COUNT), [Pin details](#AUDIT_LOG_DETAILS_PIN), [Permission overwrite details](#AUDIT_LOG_DETAILS_OVERWRITE), [Stage details](#AUDIT_LOG_DETAILS_STAGE), [Command permission details](#AUDIT_LOG_DETAILS_COMMAND_PERMISSIONS), [AutoMod details](#AUDIT_LOG_DETAILS_AUTOMOD), [Kick details](#AUDIT_LOG_DETAILS_KICK), [Role change details](#AUDIT_LOG_DETAILS_MEMBER_ROLES), [Ban details](#AUDIT_LOG_DETAILS_BAN), [Member update details](#AUDIT_LOG_DETAILS_MEMBER_UPDATE), [Role details](#AUDIT_LOG_DETAILS_ROLE), [Channel details](#AUDIT_LOG_DETAILS_CHANNEL).

### Type {#TYPE_DESCRIPTOR}

A type written as a name, or as a list or lookup table together with the type of its items.

### Any {#ANY}

Any value of any type.

### Storage field {#STORAGE_FIELD}

A storage field declared by this module or server.

### Stored value {#STORAGE_VALUE}

Value of a storage field. Its actual type is the type declared on the selected field.

### Item {#ELEMENT}

Item of the iterated list or lookup table. Its actual type is the item type of the connected collection.

### Field answer {#MODAL_FIELD_VALUE}

A member's answer to one modal field. Its actual type follows the field type: text inputs give text, dropdowns and checkbox groups give a list, a single checkbox gives true or false.

### Shape value {#RECORD}

A value with named, typed fields, following a shape declared by this module or server.

### Shape {#RECORD_TYPE}

A shape declared by this module or server. It decides which fields the shape value has and what type each of them is.

### Field of a shape value {#RECORD_FIELD}

A field of the connected shape value.

### Shape value {#RECORD_VALUE}

A shape value of the selected shape. Its fields are exactly the fields that shape declares.

### Field value {#RECORD_FIELD_VALUE}

Value of a field of a shape value. Its actual type is the type declared for that field.

### Field changes {#RECORD_PATCH}

The fields of a shape value to change, each with its new value. Fields left out keep their value.

### Choice list {#ENUM_TYPE}

One of the choice lists of this server or app.

### Choice {#ENUM_VALUE}

A value of the chosen choice list.

### Item field {#ITEM_FIELD}

A field of the items of a list.

### Matching value {#SELECTED_TYPE}

A value whose type is taken from the other values connected to the same action, so every branch of the choice returns the same type.

### Text builder {#TEXT_BUFFER}

Text you keep appending to across many steps, including inside a loop, and read out once at the end. Unlike joining text, appending changes the builder itself instead of handing back new text. Only valid inside the run that created it.

### Lookup table builder {#MAP_BUILDER}

A lookup table you keep changing across many steps, including inside a loop, and read out once at the end. Unlike the plain lookup table actions, setting on it changes the builder itself instead of handing back a new lookup table. Only valid inside the run that created it.

### List builder {#ARRAY_BUILDER}

A list you keep adding to across many steps, including inside a loop, and read out once at the end. Unlike the plain list actions, adding to it changes the builder itself instead of handing back a new list. Only valid inside the run that created it.

### Number builder {#NUMBER_BUILDER}

A running total you keep adding to across many steps, including inside a loop, and read out once at the end. It also remembers how many times you added, so you can work out an average. Only valid inside the run that created it.
