### Modal zeigen und auf Absenden warten {#show-modal-and-await-submit}

Zeigt ein Modal-Popup-Formular als Antwort auf eine Interaktion und pausiert den Flow, bis der Benutzer es absendet oder die Zeit abläuft. Ein Modal kann nur als Interaktionsantwort geöffnet werden, daher wird der Antwort-Slot dieser Interaktion verbraucht. Das Warten überlebt Bot-Neustarts, ist aber auf wenige Minuten begrenzt (so lange bleibt ein Modal im Client offen); das Absenden ist eine brandneue Interaktion, die innerhalb von 3 Sekunden beantwortet werden MUSS - antworte ihr oder verzögere sie früh in "Bei Absenden". Für ein dauerhaftes Formular verwende stattdessen "Modal zeigen" mit einem "Modal abgesendet"-Trigger.

**Eingaben**

| Name        | Typ                                                | Pflicht | Details                                                                                                                              |
| ----------- | -------------------------------------------------- | ------- | ------------------------------------------------------------------------------------------------------------------------------------ |
| Interaktion | [Interaktion](../../../value-types.md#INTERACTION) | Ja      | Die Interaktion, auf der das Modal geöffnet wird (ihr Antwort-Slot wird zum Anzeigen des Modals genutzt).                            |
| Modal       | [Modal](../../../value-types.md#MODAL)             | Ja      | Das anzuzeigende Modal-Formular, auf das gewartet wird.                                                                              |
| Zeitlimit   | [Dauer](../../../value-types.md#DURATION)          | Ja      | Wie lange auf das Absenden gewartet wird (5 Sekunden bis 15 Minuten; Standard 5 Minuten). Wert: 5000 bis 900000. Standard: `300000`. |

**Zweige**

| Name           | Details                                                                                                                                                                                                                                                                                          |
| -------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------ |
| Bei Absenden   | Wird ausgeführt, wenn der Benutzer das Modal absendet. Beantworte das Absenden (antworten oder verzögern) hier innerhalb von 3 Sekunden. Optional. Stellt seinen Schritten bereit: Absendung (Die Modal-Absende-Interaktion; lies ihre Felder per Custom-ID und antworte ihr oder verzögere sie) |
| Bei Zeitablauf | Wird ausgeführt, wenn der Benutzer das Modal nicht innerhalb des Zeitlimits absendet. Optional.                                                                                                                                                                                                  |

### Modal-Feld auslesen {#get-modal-field}

Liest eine einzelne Antwort aus einem abgesendeten Modal anhand der Custom-ID des Feldes. Der Wert entspricht dem Feldtyp: Texteingaben liefern Text, Auswahlmenüs und Checkbox-Gruppen eine Liste, eine einzelne Checkbox Ja oder Nein, und Benutzer-, Rollen-, Kanal- oder Datei-Felder die ausgewählten Einträge. Eine unbekannte Feld-ID liefert einen leeren Wert.

**Eingaben**

| Name      | Typ                                                                | Pflicht | Details                                                                                                                |
| --------- | ------------------------------------------------------------------ | ------- | ---------------------------------------------------------------------------------------------------------------------- |
| Absendung | [Modal absenden](../../../value-types.md#MODAL_SUBMIT_INTERACTION) | Ja      | Die Modal-Absendung, aus der gelesen wird.                                                                             |
| Feld      | [Text](../../../value-types.md#STRING)                             | Ja      | Custom-ID des Feldes, das gelesen wird - so, wie sie an diesem Feld im Modal gesetzt ist. Maximale Länge: 100 Zeichen. |

**Ausgaben**

| Name | Typ                                                      | Details                                                                                                  |
| ---- | -------------------------------------------------------- | -------------------------------------------------------------------------------------------------------- |
| Wert | [Feldantwort](../../../value-types.md#MODAL_FIELD_VALUE) | Die Antwort des Benutzers auf dieses Feld oder leer, wenn kein Feld diese Custom-ID hat. Kann leer sein. |
