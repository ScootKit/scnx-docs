Erstelle Nachschlagetabellen und lies, setze und entferne Werte über einen Schlüssel.

### Zuordnung: Erstellen {#create-map}

Erstellt eine neue, leere Zuordnung. Einträge werden mit "Zuordnung: Wert setzen" hinzugefügt, das jedes Mal eine neue Zuordnung zurückgibt. Um eine Zuordnung über mehrere Schritte hinweg oder in einer Schleife zu befüllen, nutze stattdessen "Zuordnungs-Builder erstellen".

**Ausgaben**

| Name | Typ | Details |
| --- | --- | --- |
| Zuordnung | Nachschlagetabelle von [Text](../../../value-types.md#STRING) zu [Text](../../../value-types.md#STRING) | Die neue leere Zuordnung. |

### Zuordnung: Wert setzen {#map-set}

Um eine Zuordnung über mehrere Schritte hinweg oder in einer Schleife zu befüllen, nutze stattdessen "Zuordnungs-Builder erstellen" und "Zuordnungs-Builder: Wert setzen".
