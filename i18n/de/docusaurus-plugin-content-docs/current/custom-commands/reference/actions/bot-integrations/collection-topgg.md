### Prüfen, ob jemand abgestimmt hat {#topgg-check-vote}

Fragt top.gg, ob ein Discord-Benutzer eine Stimme für dein Projekt hat, die noch zählt. Eine Stimme zählt 12 Stunden.

**Eingaben**

| Name        | Typ                                             | Pflicht | Details                                                                                                |
| ----------- | ----------------------------------------------- | ------- | ------------------------------------------------------------------------------------------------------ |
| Verbindung  | [Text](../../../value-types.md#STRING)          | Nein    | Die top.gg-Verbindung von der Seite Integrationen, die diese Aktion nutzt. Maximale Länge: 64 Zeichen. |
| Benutzer-ID | [Discord-ID](../../../value-types.md#SNOWFLAKE) | Ja      | Die Discord-ID der Person, die geprüft wird.                                                           |

**Ausgaben**

| Name           | Typ                                                   | Details                                                                      |
| -------------- | ----------------------------------------------------- | ---------------------------------------------------------------------------- |
| Hat abgestimmt | [Ja/Nein](../../../value-types.md#BOOLEAN)            | Ob die Person eine Stimme hat, die noch zählt.                               |
| Abgestimmt am  | [Datum und Uhrzeit](../../../value-types.md#DATETIME) | Wann die Person abgestimmt hat. Leer ohne zählende Stimme. Kann leer sein.   |
| Läuft ab am    | [Datum und Uhrzeit](../../../value-types.md#DATETIME) | Wann die Stimme nicht mehr zählt. Leer ohne zählende Stimme. Kann leer sein. |
| Gewicht        | [Ganzzahl](../../../value-types.md#INTEGER)           | Wie viel die Stimme zählt: 2 bei Wochenendstimmen, sonst 1. Kann leer sein.  |
