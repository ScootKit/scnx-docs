### Text mit KI übersetzen {#ai-translate-text}

Übersetzt Text mit KI in eine andere Sprache. Jede Übersetzung kostet einen AI Coin vom Guthaben dieses Servers, und der Coin wird nur verbraucht, wenn tatsächlich eine Übersetzung zurückkommt. Ist das Guthaben leer, schlägt die Aktion mit dem Fehlercode AI_CREDITS_EXHAUSTED fehl. Diesen Code kannst du mit "Versuchen" abfangen und stattdessen den Originaltext verwenden. In einem Testlauf wird nichts übersetzt und es werden keine AI Coins verbraucht.

| Name            | Typ                                    | Pflicht | Details                                                                                                                                                                                                                                                                    |
| --------------- | -------------------------------------- | ------- | -------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| Text            | [Text](../../../value-types.md#STRING) | Ja      | Der Text, der übersetzt werden soll (bis zu 2000 Zeichen). Discord-Formatierung, Erwähnungen und Emojis bleiben unverändert. Länge: 1 bis 2000 Zeichen.                                                                                                                    |
| Zielsprache     | [Text](../../../value-types.md#STRING) | Ja      | Die Sprache, in die übersetzt werden soll. Alles, was die KI versteht, funktioniert, zum Beispiel Deutsch, Englisch, de oder pt-BR. Du kannst hier auch eine Option deines Slash-Befehls verknüpfen, damit Benutzer die Sprache selbst auswählen. Länge: 2 bis 40 Zeichen. |
| Ausgangssprache | [Text](../../../value-types.md#STRING) | Nein    | Optional: die Sprache, in der der Text verfasst ist. Leer lassen, damit die KI sie automatisch erkennt. Maximale Länge: 40 Zeichen.                                                                                                                                        |

### HTTP-Anfrage senden {#http-request}

Ruft eine Web-API über HTTPS auf und gibt dir die Antwort. Jede Anfrage verbraucht einen Teil des Aktivitätsbudgets dieses Servers. Nutze eine vollständige URL oder eine gespeicherte Verbindung mit Pfad, damit der API-Schlüssel verschlüsselt bleibt. Eine Antwort mit Fehlerstatus wie 404 ist kein Fehlschlag: Prüfe "Status" oder "Erfolgreich". Ist die API nicht erreichbar, schlägt die Aktion mit einem Code fehl, der mit HTTP_ beginnt, und du kannst sie mit 'Versuchen' abfangen. In einem Testlauf werden nur GET-Anfragen gesendet, andere Methoden liefern eine leere Antwort.

### Webhook beantworten {#respond-to-webhook}

Sendet die Antwort auf die Webhook-Anfrage, die diesen Flow gestartet hat. Funktioniert nur in Flows, die ein Webhook startet, der auf eine Antwort wartet. Die erste Antwort gewinnt, spätere werden nicht gesendet. Die Antwort muss innerhalb von 25 Sekunden nach der Anfrage kommen. Jede Antwort verbraucht einen Teil des Aktivitätsbudgets dieses Servers.
