Aktionen in der Kategorie "Flows".

### Anderen Flow ausführen {#call-flow}

Führt einen anderen Flow synchron aus (sein Auslöser muss ein manueller Auslöser sein). Vom Ziel definierte Parameter erscheinen als typisierte Argument-Eingaben; definierte Rückgabewerte werden zu Ausgaben dieses Schritts.

**Eingaben**

| Name      | Typ                                            | Pflicht | Details                                                                                                                                                                              |
| --------- | ---------------------------------------------- | ------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------ |
| Ziel-Flow | [Flow](../../../value-types.md#FLOW_REFERENCE) | Ja      | Flow, der ausgeführt wird. Die von seinem manuellen Auslöser definierten Parameter erscheinen hier als typisierte Argumente; seine Rückgabewerte werden zu Ausgaben dieses Schritts. |

### Flow-Ausführung planen {#schedule-flow-run}

Plant die einmalige Ausführung eines anderen Flows zu einem bestimmten Zeitpunkt. Geplante Ausführungen werden gespeichert und überleben Neustarts; vom Ziel definierte Parameter erscheinen als typisierte Argument-Eingaben.

**Eingaben**

| Name         | Typ                                                   | Pflicht | Details                                                                                                                                                              |
| ------------ | ----------------------------------------------------- | ------- | -------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| Ausführen am | [Datum und Uhrzeit](../../../value-types.md#DATETIME) | Ja      | Wann der Ziel-Flow ausgeführt werden soll.                                                                                                                           |
| Ziel-Flow    | [Flow](../../../value-types.md#FLOW_REFERENCE)        | Ja      | Flow, der ausgeführt werden soll. Sein Auslöser muss ein "Geplante Ausführung"-Auslöser sein; von ihm definierte Parameter erscheinen hier als typisierte Argumente. |

**Ausgaben**

| Name           | Typ                                    | Details                                                                                                                                                  |
| -------------- | -------------------------------------- | -------------------------------------------------------------------------------------------------------------------------------------------------------- |
| Ausführungs-ID | [Text](../../../value-types.md#STRING) | Kennung der geplanten Ausführung. Aufbewahren (zum Beispiel im Speicher), um die Ausführung später mit "Geplante Flow-Ausführung abbrechen" abzubrechen. |

### Geplante Flow-Ausführung abbrechen {#cancel-scheduled-flow-run}

Bricht anhand der Ausführungs-ID aus "Flow-Ausführung planen" eine geplante Ausführung ab, die noch nicht stattgefunden hat. Sowohl der gespeicherte Eintrag als auch der bereits laufende Timer werden entfernt, sodass die Ausführung nicht mehr starten kann.

**Eingaben**

| Name           | Typ                                    | Pflicht | Details                                                                                                        |
| -------------- | -------------------------------------- | ------- | -------------------------------------------------------------------------------------------------------------- |
| Ausführungs-ID | [Text](../../../value-types.md#STRING) | Ja      | Kennung aus "Flow-Ausführung planen" oder aus "Geplante Flow-Ausführungen auflisten". Länge: 1 bis 64 Zeichen. |

**Ausgaben**

| Name        | Typ                                        | Details                                                                                                                                                                                           |
| ----------- | ------------------------------------------ | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| Abgebrochen | [Ja/Nein](../../../value-types.md#BOOLEAN) | Wahr, wenn eine ausstehende Ausführung abgebrochen wurde. Falsch (kein Fehler), wenn sie bereits gelaufen ist, bereits abgebrochen wurde oder außerhalb dieses Moduls oder Servers geplant wurde. |

| Limit     | [Ganzzahl](../../../value-types.md#INTEGER)    | Ja      | Maximale Anzahl zurückgegebener geplanter Ausführungen (die nächste zuerst). Wert: 1 bis 5000. Standard: `25`. |

### Benutzerdefiniertes Event auslösen {#emit-custom-event}

Löst ein benanntes benutzerdefiniertes Event auf diesem Server aus. Jeder Flow mit einem "Benutzerdefiniertes Event empfangen"-Auslöser mit demselben Event-Namen läuft als eigene Ausführung. Damit lässt sich Arbeit zwischen Flows verteilen.

**Eingaben**

| Name       | Typ                                                                                                     | Pflicht | Details                                                                                                                                                                                                                                    |
| ---------- | ------------------------------------------------------------------------------------------------------- | ------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------ |
| Event-Name | [Text](../../../value-types.md#STRING)                                                                  | Ja      | Name des auszulösenden Events. Flows, die auf genau diesen Namen hören, werden ausgeführt. Länge: 1 bis 100 Zeichen.                                                                                                                       |
| Nutzdaten  | Nachschlagetabelle von [Text](../../../value-types.md#STRING) zu [Text](../../../value-types.md#STRING) | Nein    | Optionale Daten, die mitgegeben werden. Legt dieser Server oder dieses Modul einen Nutzdaten-Typ für das Event fest, müssen die Daten dazu passen. Sonst werden sie als Text-Schlüssel/Wert-Paare gesendet und Nicht-Text-Werte verworfen. |

### Flow-Cooldown abrufen {#get-flow-cooldown}

Liest den verbleibenden Trigger-Cooldown eines Flows. Achtung: Ein Flow kann damit nie seinen eigenen Lauf steuern - sein Fenster öffnet sich schon bei der Zulassung des Laufs und ist deshalb immer aktiv. Nutze es, um anderen zu sagen, wie lange sie warten müssen, oder richte es auf einen anderen Flow. Der Geltungsbereich (Benutzer, Kanal oder Server) ist der am Trigger eingestellte; nach dem Fortsetzen aus einer Wartephase gilt der Wert serverweit.

**Eingaben**

| Name | Typ                                            | Pflicht | Details                                                                 |
| ---- | ---------------------------------------------- | ------- | ----------------------------------------------------------------------- |
| Flow | [Flow](../../../value-types.md#FLOW_REFERENCE) | Nein    | Flow, dessen Cooldown gelesen wird. Leer lassen für den aktuellen Flow. |

**Ausgaben**

| Name        | Typ                                        | Details                                                                                                                                                                                                                  |
| ----------- | ------------------------------------------ | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------ |
| Im Cooldown | [Ja/Nein](../../../value-types.md#BOOLEAN) | Wahr, solange das Cooldown-Zeitfenster noch offen ist. Während des eigenen Laufs dieses Flows ist der Wert fast immer wahr, weil das Fenster bei der Zulassung des Laufs geöffnet wurde.                                 |
| Erneut ab   | [Dauer](../../../value-types.md#DURATION)  | Verbleibende Zeit bis zum Ende des Cooldowns (0, wenn keiner aktiv ist oder der Trigger keinen Cooldown hat). Während des eigenen Laufs dieses Flows entspricht der Wert aus demselben Grund fast dem gesamten Cooldown. |

### Aus Flow zurückkehren {#return-from-flow}

Beendet diesen Flow und übergibt die definierten Rückgabewerte an den aufrufenden Flow. Nur nutzbar, wenn der Auslöser Rückgabewerte definiert; nicht gesetzte Werte werden leer zurückgegeben.
