### Audit-Log-Eintrag nach ID abrufen {#fetch-audit-log-entry-by-id}

Ruft einen einzelnen Audit-Log-Eintrag aus einem Server nach seiner ID ab. Gibt einen leeren Wert zurück, wenn kein solcher Eintrag existiert.

**Eingaben**

| Name | Typ | Pflicht | Details |
| --- | --- | --- | --- |
| Eintrags-ID | [Discord-ID](../../../value-types.md#SNOWFLAKE) | Ja | Discord-ID des Audit-Log-Eintrags, der abgerufen wird. |

**Ausgaben**

| Name | Typ | Details |
| --- | --- | --- |
| Eintrag | [Audit-Log-Eintrag](../../../value-types.md#AUDIT_LOG_ENTRY) | Der abgerufene Audit-Log-Eintrag oder leer, wenn nicht gefunden. Kann leer sein. |

| Name | Typ | Details |
