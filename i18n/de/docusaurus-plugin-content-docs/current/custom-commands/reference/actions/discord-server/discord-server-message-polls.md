### Umfrage erstellen {#create-poll}

Erstellt eine neue Umfrage-Nachricht in einem Kanal mit einfachen Antworteingaben.

Benötigte Berechtigungen: Umfragen erstellen.

**Eingaben**

| Name | Typ | Pflicht | Details |
| --- | --- | --- | --- |
| Kanal | [Server-Kanal](../../../value-types.md#GUILD_CHANNEL) | Ja | Kanal, in dem die Umfrage veröffentlicht wird. |
| Frage | [Text](../../../value-types.md#STRING) | Ja | Die Umfrage-Frage (max. 300 Zeichen). Länge: 1 bis 300 Zeichen. |
| Antworten | Liste von [Umfrage-Antwort](../../../value-types.md#POLL_ANSWER_INPUT) | Ja | Liste der Umfrage-Antworten (1-10). Einträge: 1 bis 10. |
| Dauer (Stunden) | [Ganzzahl](../../../value-types.md#INTEGER) | Nein | Wie lange die Umfrage geöffnet bleibt, in Stunden (1-768). Wert: 1 bis 768. Standard: `24`. |
| Mehrere Antworten erlauben | [Ja/Nein](../../../value-types.md#BOOLEAN) | Nein | Ob Abstimmende mehr als eine Antwort auswählen dürfen. Standard: Nein. |

**Ausgaben**

| Name | Typ | Details |
| --- | --- | --- |
| Umfrage-Nachricht | [Nachricht](../../../value-types.md#MESSAGE) | Die Umfrage-Nachricht, die gesendet wurde. |
