Integriere mit APIs und unterstützten Drittanbieter-Anbietern.

### Webhook empfangen {#webhook}

Läuft, wenn ein anderer Dienst eine Anfrage an einen Webhook dieses Servers sendet. Lege Webhooks auf der Integrationsseite an und wähle hier einen aus. Jeder Lauf verbraucht einen Teil des Aktivitätsbudgets dieses Servers. Wartet der Webhook auf eine Antwort, hat der Flow 25 Sekunden Zeit, mit "Webhook beantworten" zu antworten.

**Einstellungen**

| Name | Typ | Pflicht | Details |
| --- | --- | --- | --- |
| Webhook | [Text](../../../value-types.md#STRING) | Ja | Der Webhook, der diesen Flow startet. Länge: 1 bis 64 Zeichen. |
| Nur bei Header | [Text](../../../value-types.md#STRING) | Nein | Optional: nur ausführen, wenn die Anfrage diesen Header hat, zum Beispiel X-GitHub-Event. Setze dann auch den Header-Wert. Maximale Länge: 100 Zeichen. |
| Header-Wert | [Text](../../../value-types.md#STRING) | Nein | Optional: der genaue Wert, den der Header haben muss, zum Beispiel push. Maximale Länge: 500 Zeichen. |
| Inhaltsstruktur | [Struktur](../../../value-types.md#RECORD_TYPE) | Nein | Optional: eine Struktur, in die der Inhalt der Anfrage eingelesen wird. Das Ergebnis steht in "Inhalt". |

**Bereitgestellte Werte**

| Name | Typ | Details |
| --- | --- | --- |
| Inhalt | [Beliebig](../../../value-types.md#ANY) | Der Inhalt der Anfrage aus JSON oder Formulardaten, als Strukturwert, wenn eine Inhaltsstruktur gesetzt ist. Leer, wenn er nicht gelesen werden konnte. Kann leer sein. |
| Inhaltsproblem | [Text](../../../value-types.md#STRING) | Warum der Inhalt nicht gelesen werden konnte oder nicht zur Inhaltsstruktur passt. Leer, wenn alles geklappt hat. Kann leer sein. |
| Inhalt als Text | [Text](../../../value-types.md#STRING) | Der Inhalt der Anfrage als Text, genau so, wie er ankam. Leer, wenn er kein Text ist. Kann leer sein. |
| Header | Nachschlagetabelle von [Text](../../../value-types.md#STRING) zu [Text](../../../value-types.md#STRING) | Die Header der Anfrage mit kleingeschriebenen Namen. Cookies und Anmelde-Header werden entfernt. |
| Abfrageparameter | Nachschlagetabelle von [Text](../../../value-types.md#STRING) zu [Text](../../../value-types.md#STRING) | Die Namen und Werte nach dem ? in der Adresse. |
| Methode | [Text](../../../value-types.md#STRING) | Die HTTP-Methode der Anfrage: GET, POST, PUT oder PATCH. |
| Zustellungs-ID | [Text](../../../value-types.md#STRING) | Eine eindeutige ID dieser Zustellung. Eine Zustellung kann doppelt ankommen; speichere die ID, um Wiederholungen zu überspringen. |
| Webhook-Name | [Text](../../../value-types.md#STRING) | Der Name des Webhooks, der die Anfrage empfangen hat. |
