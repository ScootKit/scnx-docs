Führt diesen Flow aus, wenn jemand auf deinem Server gebannt oder entbannt wird.

### Mitglied gebannt {#member-banned}

Wird ausgelöst, wenn ein Mitglied vom Server gebannt wird.

Benötigte Intents: `GuildModeration`.

**Bereitgestellte Werte**

| Name | Typ                                       | Details             |
| ---- | ----------------------------------------- | ------------------- |
| Bann | [Bann](../../../value-types.md#GUILD_BAN) | Der erstellte Bann. |

### Mitglied entbannt {#member-unbanned}

Wird ausgelöst, wenn ein zuvor gebannter Benutzer entbannt wird.

Benötigte Intents: `GuildModeration`.

**Bereitgestellte Werte**

| Name     | Typ                                              | Details                                    |
| -------- | ------------------------------------------------ | ------------------------------------------ |
| Benutzer | [Benutzer](../../../value-types.md#DISCORD_USER) | Der Benutzer, der entbannt wurde.          |
| Server   | [Server](../../../value-types.md#GUILD)          | Der Server, auf den sich der Bann bezieht. |
