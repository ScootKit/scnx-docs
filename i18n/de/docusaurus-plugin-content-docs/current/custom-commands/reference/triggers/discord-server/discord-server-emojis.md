### Emoji erstellt {#emoji-created}

Wird ausgelöst, wenn ein benutzerdefiniertes Emoji auf einem Server erstellt wird.

Benötigte Intents: `GuildExpressions`.

| Name  | Typ                                                 | Details                    |

| Emoji | [Server-Emoji](../../../value-types.md#GUILD_EMOJI) | Emoji, das erstellt wurde. |

Wird ausgelöst, wenn ein benutzerdefiniertes Emoji von einem Server gelöscht wird.

Benötigte Intents: `GuildExpressions`.

**Bereitgestellte Werte**

| Name  | Typ                                                 | Details                    |
| ----- | --------------------------------------------------- | -------------------------- |
| Emoji | [Server-Emoji](../../../value-types.md#GUILD_EMOJI) | Emoji, das gelöscht wurde. |
