Trigger in der Kategorie "Server-Einstellungen".

### Server-Onboarding aktualisiert {#guild-onboarding-updated}

Wird ausgelöst, wenn die Onboarding-Konfiguration eines Servers geändert wird (abgeleitet aus dem Audit-Log - der Bot benötigt die Berechtigung "Audit-Log einsehen"). Die vorherige Konfiguration ist nicht verfügbar und immer leer.

Benötigte Intents: `GuildModeration`.

**Ausgaben**

| Name                  | Typ                                                           | Details                                                    |
| --------------------- | ------------------------------------------------------------- | ---------------------------------------------------------- |
| Server                | [Server](../../../value-types.md#GUILD)                       | Server, dessen Onboarding sich geändert hat.               |
| Vorheriges Onboarding | [Server-Onboarding](../../../value-types.md#GUILD_ONBOARDING) | Onboarding-Status vor der Aktualisierung. Kann leer sein.  |
| Aktuelles Onboarding  | [Server-Onboarding](../../../value-types.md#GUILD_ONBOARDING) | Onboarding-Status nach der Aktualisierung. Kann leer sein. |

### Willkommensbildschirm aktualisiert {#welcome-screen-updated}

Wird ausgelöst, wenn der Willkommensbildschirm DURCH EINEN FLOW geändert wird (Aktion "Willkommensbildschirm aktualisieren"). Änderungen direkt im Discord-Client lösen diesen Trigger nicht aus.

**Ausgaben**

| Name                  | Typ                                                              | Details                                                 |
| --------------------- | ---------------------------------------------------------------- | ------------------------------------------------------- |
| Server                | [Server](../../../value-types.md#GUILD)                          | Server, dessen Willkommensbildschirm sich geändert hat. |
| Vorheriger Bildschirm | [Willkommens-Bildschirm](../../../value-types.md#WELCOME_SCREEN) | Willkommensbildschirm vor der Aktualisierung.           |
| Aktueller Bildschirm  | [Willkommens-Bildschirm](../../../value-types.md#WELCOME_SCREEN) | Willkommensbildschirm nach der Aktualisierung.          |
